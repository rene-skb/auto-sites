# Panel notes — Pacificland Constructors

## Creative direction

Build a quote-first masonry/concrete page for a Lakewood contractor. The site should feel sturdy, source-backed, and practical: real project photos, exact license number, official contact details, and a clear service scope for LA/Orange County property owners.

## WHY critique — v0

**Steve Jobs — 7.8**
- The visual point of view lands: warm concrete, brick oxide, hard-shadow project photography, and a bold hero feel specific to masonry work.
- The main headline is stylish but one step too abstract. The user should know the trade scope before reading body copy.
- The project image deserves a little more authority; completed work should feel like the product.

**Paul Graham — 7.5**
- The facts are good, but some section headlines sound like agency copy instead of a homeowner trying to hire a contractor.
- “Actual work, not stock construction gloss” is true, but it talks about the redesign rather than the customer’s project.
- Remove footer/source-language leakage. It breaks trust instantly.

**David Ogilvy — 7.9**
- The proof strip is strong: phone, Lakewood, license, LA/OC.
- The first screen should say concrete, masonry, stonework, pavers, foundations, retaining walls without making the visitor hunt.
- CTA checklist boxes look like fields. If they are a checklist, make them read like one.

**WHY average: 7.73**

**Changes for v1**
1. Make the hero headline/service scope more direct.
2. Remove demo/source-backed footer language.
3. Reword clever section titles into contractor-facing, practical language.
4. Fix the project caption crop and turn CTA chips into checklist items.

## WHAT critique — v1

**Don Norman — 8.0**
- Primary call CTA is visible and the license/address details build confidence.
- The estimate path should explain what happens after calling, closer to the first screen.
- Mobile users need a persistent tappable call affordance.

**Steve Krug — 7.8**
- The category and geography are understandable, but nav labels can be plainer.
- “Proof” is less clear than “License + Trust.” “Projects” should become “Project Gallery.”
- Service confirmation should happen faster with compact chips near the hero.

**Jakob Nielsen — 7.7**
- Recognition should beat recall: visitors should instantly see concrete, masonry, foundations, pavers, retaining walls.
- Make the license directly checkable via the CSLB link already published by the official site.
- Large type and generous spacing are polished but may create mobile scrolling cost.

**WHAT average: 7.83**

**Changes for v2**
1. Add service chips below hero copy.
2. Rename nav labels to Project Gallery and License + Trust.
3. Make CSLB license proof clickable.
4. Add sticky mobile call bar.
5. Reduce extreme display sizing slightly for mobile/readability.

## HOW critique — v2

**Massimo Vignelli — 8.2**
- Strong modular structure and section contrast.
- Hero text and image card need a more deliberate alignment; current image sits a little detached.
- Standardize visual rhythm and avoid awkward hero line breaks.

**Erik Spiekermann — 7.8**
- Bold type fits a contractor, but the hero creates too many heavy line breaks.
- Body copy is readable; dark-section copy can be a bit brighter.
- Header/logo could use more presence against the cream nav.

**Dieter Rams — 8.5**
- Service scope, license, and CTA are useful.
- Service chips risk clutter but are defensible for recognition; make them quieter and less decorative.
- Add captions to every gallery image so proof stays concrete.

**Emil Kowalski — 8.0**
- Motion should stay restrained: shorter translate distance, custom easing, no image hover on non-clickable photos.
- Add interaction feedback to nav links and CTAs only.
- Reduce the hero-card shadow so it feels less glossy.

**HOW average: 8.13**

**Changes for v3**
1. Tighten hero width and increase line-height slightly to avoid awkward black wall breaks.
2. Align hero media more intentionally and reduce the soft shadow.
3. Quiet the service chips rather than removing them.
4. Add labels to all gallery photos.
5. Add nav/link feedback while respecting no-hover-on-static-images.
6. Shorten scroll reveal distance from 24px to 16px.

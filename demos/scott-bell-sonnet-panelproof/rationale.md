# Scott Bell Sonnet Panelproof — Rationale

## Slug
- `scott-bell-sonnet-panelproof`

## Intent
This run was a panel-proof test after patching the auto-site-builder skill. The primary goal was not to invent a radically new Scott portfolio concept. The goal was to prove the repaired pipeline end to end: real WHY / WHAT / HOW panel artifacts, explicit iteration deltas, canonical inner-repo publishing, and a live Pages route.

Still, the page needed to feel fresh enough to justify the exercise. So this version moved away from the darker editorial tone of recent Sonnet runs and into a lighter, daylight portfolio direction.

## Creative direction
- **Mood:** clean, calm, precise, present-tense
- **Hero pattern:** `split-image-right`
- **Typography:** Libre Baskerville (display) + Manrope (body/UI)
- **Palette:** off-white paper, near-black ink, restrained green accent
- **Structure:** Hero → Selected Work → inline CTA → Current Work → About → Contact

## Why this direction
The recent Scott portfolio builds already covered:
- dark editorial warmth
- giant display-name hero treatments
- split numeric hero treatments
- bolder teal / violet / amber accent directions

This build needed a different lane. The answer was a lighter layout with more breathing room, a split-image hero, and a green accent that signals current activity instead of résumé nostalgia.

## Core positioning choice
The strongest claim in the brief was not just 14 years or 24 products. It was the fact that Scott has shipped roughly six self-initiated things recently. That's the unusual proof. Senior product design experience is common. Senior product design experience plus current maker momentum is not.

So the page leads with:
- tenure
- breadth
- present-tense shipping

That let the portfolio feel current instead of retrospective.

## What changed through the panels
### WHY pass
- removed the redundant proof strip
- cut the current-work section from a sprawling grid to the 3 strongest signals
- moved the strongest Nakamoto fact into the lead
- reframed the closing CTA from what Scott wants to what a team gets

### WHAT pass
- made the offer more explicit under the hero headline
- renamed `Now` to `Current Work`
- reduced case-study density by using one image per case
- added an inline CTA before the footer
- improved metadata scanability

### HOW pass
- unified the page grid by turning Current Work into editorial rows
- tightened the type system
- trimmed unnecessary pills and repeated explanation
- standardized screenshot framing
- set up a restrained motion plan

### Final self-review pass
- rebalanced the hero headline so it felt less like a tall text tower
- tightened copy in the middle sections
- strengthened section labels and final CTA presence

## What this build is trying to prove
1. Scott has deep product-design credibility from real shipped work
2. He is not only a portfolio historian. He is building right now
3. His best fit is AI-native product work, agent UX, design systems, and 0-to-1 environments
4. He closes the loop: design plus build, not just design plus decks

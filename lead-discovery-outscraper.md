# Lead Discovery — Outscraper Setup

## What It Does
Outscraper scrapes Google Maps and can filter businesses that have NO website listed. Perfect for Auto-Sites lead gen.

## Free Tier
- Monthly renewable free credits
- Enough for ~500 business lookups/month
- No credit card required to start

## How to Find Businesses Without Websites

### Via Outscraper Web UI (easiest)
1. Sign up at outscraper.com
2. Go to Google Maps Scraper
3. Search query: `barbershop Victoria BC` (or any category)
4. Set filters: **Website = empty/none**
5. Export results as CSV
6. Columns you get: name, address, phone, rating, reviews count, category

### Categories to Search (Victoria BC)
Priority order (businesses most likely to pay for a site):
1. **Barbershops / hair salons** — personal brand matters, walk-in traffic
2. **Restaurants / cafes** — already have menu on Google, but a site converts better
3. **Fitness / yoga studios** — need class schedules, booking
4. **Retail / boutiques** — product showcase
5. **Trades** (plumbers, electricians) — need trust/credibility pages
6. **Pet services** — groomers, walkers, boarding

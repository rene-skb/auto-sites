# Non-Negotiables — Scott's Rules

*These override EVERYTHING. Panel feedback, design knowledge, lessons, personal judgment. If a reviewer suggests something that contradicts these rules, IGNORE the reviewer.*

*Only Scott can add to or modify this file.*

---

❌ **NO checkerboard review cards.** ALL review/testimonial cards must use the SAME visual treatment. No alternating dark/light. No featured card with different background. Content provides variety, not card styling.

❌ **NO fake storefronts, interiors, or building exteriors.** Use product shots, textures, ingredients, mood photos, close-ups. Things that evoke the vibe without pretending to be the actual place.

❌ **NO hover zoom/scale on non-clickable images.** Scroll-reveal animations ONLY for editorial images. Hover effects are for buttons, links, and interactive elements.

❌ **NO reusing the same image twice on one page.** Each image slot is unique.

❌ **NO body text blocks longer than 2-3 sentences.** Landing pages are not blog posts. Every word earns its place.

❌ **NO double stats bars stacked.** One stats section or zero. Never two.

❌ **Asymmetric grids: both sides end at the same baseline.** No dead space gaps at the bottom of image grids. If images don't fill evenly, use equal columns instead.

❌ **Review cards MUST have first name + last initial.** "Sarah M." not anonymous "Via Google." Best format: name + date + source ("NEIL · MAY 2024 · Via Google").

❌ **Hero answers "why should I come here?"** Not the business origin story. Not the founders' ages. Lead with value, vibe, or product. Save history for the story section.

❌ **Noise texture: very fine grain only.** If you can see individual particles, it's too heavy. Film grain, not sandpaper. When in doubt, skip it entirely.

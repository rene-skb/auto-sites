How it works
01

Activate

Press ⌘⇧C or click the extension icon to enter capture mode. Your cursor becomes a precision instrument.

02

Click

Click any element. LoopIn captures DOM structure, computed styles, accessibility data, and React component hierarchy in one shot.

03

Send

Add context and send directly to your agent via MCP. Your agent knows exactly what you're looking at. Zero copy-paste.

Architecture
All data stays local. Nothing leaves your machine.
Browser → LoopIn → MCP Server → AI Agent

What your agent gets

One click.
Six layers of context.

Not a screenshot. Not a description. Structured, machine-readable data your agent can reason about and act on precisely.

HTML

Element

Tag name, classes, and rendered inner content exactly as the browser sees it.

CSS

Styles

Computed colors, spacing, typography, and layout — not just the stylesheet, the real values.

DOM

Selector

Unique, unambiguous path to the element. No more "the blue button in the nav."

A11Y

Accessibility

ARIA roles, labels, and attributes surfaced automatically — issues your agent can fix immediately.

JSX

Components

Full React component hierarchy via the fiber tree. Your agent knows what component rendered this.

CTX

Context

Heading hierarchy and data attributes that situate the element within the page.
